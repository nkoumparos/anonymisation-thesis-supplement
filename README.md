# Συμπληρωματικό υλικό διπλωματικής εργασίας

**Προστασία ιδιωτικότητας με χρήση τεχνικών ανωνυμοποίησης**

Συγκεντρωτικά αποτελέσματα, πηγές δεδομένων, τεκμηρίωση των ιεραρχιών γενίκευσης, πειραματικές ρυθμίσεις και πηγαίος κώδικας.

Αποθετήριο: [nkoumparos/anonymisation-thesis-supplement](https://github.com/nkoumparos/anonymisation-thesis-supplement)

## Ανάγνωση του υλικού

Ανοίξτε το `index.html` για ανάγνωση χωρίς σύνδεση στο διαδίκτυο. Το [ευρετήριο](contents.md) αντιστοιχίζει τα αρχεία στις ενότητες και στους πίνακες της εργασίας. Ο [οδηγός ανάγνωσης](guide.md) εξηγεί τις βασικές μετρήσεις και το [λεξικό στηλών](results/DATA_DICTIONARY_EL.md) ορίζει κάθε πεδίο των CSV.

| Φάκελος | Περιεχόμενο |
|---|---|
| [results/](results/RESULTS_README_EL.md) | 16 κύριοι και 5 βοηθητικοί πίνακες CSV, μαζί με τις πλήρεις συγκεντρωτικές δομές σε JSON. |
| [data_sources/](data_sources/README.md) | Πηγές Adult, αποτυπώματα SHA-256 και οδηγίες απόκτησης και προετοιμασίας. |
| [hierarchies/](hierarchies/README.md) | Τεκμηρίωση για τις οκτώ ιεραρχίες γενίκευσης και τη διόρθωση των ετικετών ηλικίας. |
| [configuration/](configuration/README.md) | Διαμορφώσεις, σενάρια, παράμετροι μοντέλου και σπόροι ψευδοτυχαίων διεργασιών. |
| [figures/](figures/README.md) | Τα πέντε σχήματα σε PNG, SVG και PDF, με σημειώσεις και δεδομένα απεικόνισης. |
| [environment/](environment/README.md) | Εκδόσεις εργαλείων και εξαρτήσεις Python. |
| [code/](code/README.md) | Επιλεγμένα αρχεία της υλοποίησης και εργαλείο αναδημιουργίας των CSV. |

Τα δεδομένα Adult αποκτώνται χωριστά από τις δηλωμένες πηγές. Δεν περιλαμβάνονται ατομικές προβλέψεις, αντιστοιχίσεις εγγραφών ή έξοδοι με ευθυγραμμισμένη σειρά εγγραφών. Η πλήρης επανεκτέλεση των πειραμάτων σε νέο περιβάλλον δεν παρέχεται ως έτοιμη λειτουργία.

Οι [οδηγίες ελέγχου και χρήσης](docs/VALIDATION_AND_USE.md) καλύπτουν την ακεραιότητα των αρχείων και τα όρια αναπαραγωγής. Οι [πηγές και άδειες](data_sources/RIGHTS_AND_SOURCES.md) προσδιορίζονται χωριστά ανά κατηγορία υλικού.
