# Υπολογιστικό περιβάλλον

Τα συγκεντρωτικά αποτελέσματα διαβάζονται χωρίς εγκατάσταση του πειραματικού περιβάλλοντος. Οι ακριβείς εκδόσεις συνοψίζονται στον Πίνακα 4.6 της §4.8 της εργασίας. Τα παρακάτω αρχεία καταγράφουν το περιβάλλον των πειραμάτων.

| Αρχείο | Χρήση |
|---|---|
| [environment.json](environment.json) | Βασικά εργαλεία, στοιχεία ταυτότητας του αρχείου ARX και προέλευση των καταγεγραμμένων εκδόσεων |
| [python_dependencies.csv](python_dependencies.csv) | Κατάλογος 30 καταγεγραμμένων εξαρτήσεων |
| [requirements-win-py312.txt](requirements-win-py312.txt) | Εκδόσεις και SHA-256 των αρχείων εγκατάστασης Python |

Το αρχείο απαιτήσεων αφορά CPython 3.12.10 σε Windows x86-64. Δεν περιλαμβάνονται εκτελέσιμα προγραμμάτων, βιβλιοθήκες τρίτων ή αρχικές καταγραφές εγκατάστασης και εκτέλεσης.

Για διαφορετικό λειτουργικό σύστημα ή έκδοση Python απαιτείται επίλυση εξαρτήσεων και έλεγχος συμβατότητας. Δεν έχει επαληθευτεί πλήρης επανεκτέλεση των πειραμάτων σε άλλο περιβάλλον.

## Επαληθευμένες εκδόσεις και τεκμήρια

| Εργαλείο | Ακριβής έκδοση | Τεκμηρίωση |
|---|---|---|
| ARX | 3.9.2 | Το αρχείο `libarx-3.9.2.jar` και το SHA-256 του καταγράφονται στις τελικές εκτελέσεις. |
| Python | CPython 3.12.10, 64 bit | Καταγραφή εγκατάστασης και καταγραφές εκπαίδευσης της 14/09/2026. |
| Java | OpenJDK 21.0.12.1, 64 bit | Ίδια έκδοση στις αναφορές και των 16 τελικών εξόδων ARX. |
| NumPy | 2.0.2 | Καταγραφή εγκατάστασης και καταγραφές εκπαίδευσης της 14/09/2026. |
| scikit-learn | 1.9.0 | Καταγραφή εγκατάστασης και καταγραφές εκπαίδευσης της 14/09/2026. |
| pandas | 2.3.3 | Καταγραφή των πραγματικά εγκατεστημένων πακέτων της 05/09/2026. |
| SciPy | 1.15.3 | Καταγραφή των πραγματικά εγκατεστημένων πακέτων της 05/09/2026. |
| pyCANON | 1.3.6 | Καταγραφή των πραγματικά εγκατεστημένων πακέτων της 05/09/2026. |
| Λειτουργικό σύστημα | Windows 11, x86-64 | Αναφορές των τελικών εκτελέσεων ARX. |

Η πλήρης έκδοση της Java είναι Microsoft OpenJDK `21.0.12.1+1-LTS`. Για τις pandas, SciPy και pyCANON η τεκμηρίωση αφορά την καταγραφή εγκατεστημένων πακέτων της 05/09/2026, όχι νέα καταγραφή στις τελικές εκτελέσεις.
