Υπολογιστικό περιβάλλον

Τα συγκεντρωτικά αποτελέσματα διαβάζονται χωρίς εγκατάσταση του πειραματικού περιβάλλοντος. Οι ακριβείς εκδόσεις συνοψίζονται στον Πίνακα 4.6 της §4.8 της εργασίας. Τα παρακάτω αρχεία καταγράφουν το περιβάλλον των πειραμάτων.

Αρχείο Χρήση
environment.json Βασικά εργαλεία, στοιχεία ταυτότητας του αρχείου ARX και προέλευση των καταγεγραμμένων εκδόσεων
python_dependencies.csv Κατάλογος 30 καταγεγραμμένων εξαρτήσεων
requirements-win-py312.txt Εκδόσεις και SHA-256 των αρχείων εγκατάστασης Python

Το αρχείο απαιτήσεων αφορά CPython 3.12.10 σε Windows x86-64. Δεν περιλαμβάνονται εκτελέσιμα προγραμμάτων, βιβλιοθήκες τρίτων ή αρχικές καταγραφές εγκατάστασης και εκτέλεσης.

Για διαφορετικό λειτουργικό σύστημα ή έκδοση Python απαιτείται επίλυση εξαρτήσεων και έλεγχος συμβατότητας. Δεν έχει επαληθευτεί πλήρης επανεκτέλεση των πειραμάτων σε άλλο περιβάλλον.
