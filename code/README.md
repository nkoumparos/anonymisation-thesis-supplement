# Πηγαίος κώδικας

| Θέση | Περιεχόμενο |
|---|---|
| `export_aggregate_tables.py` | Αναδημιουργία των CSV από το `results/aggregates.json`. |
| `verified_sources/python/` | Απόκτηση και έλεγχος δεδομένων, ιεραρχία ηλικίας, μετασχηματισμοί, ταξινόμηση, σύνδεση εγγραφών και επαναδειγματοληψία. |
| `verified_sources/java/` | Διαμορφώσεις, μετασχηματισμοί και έλεγχοι του ARX. |
| `sensitivity_sources/python/` | Σενάρια S1–S4 και διαγνωστικά κλάσεων, ισοπαλιών και κατανομών. |
| `sensitivity_sources/frozen_python/` | Εξαρτήσεις της υλοποίησης S1–S4. |
| `runtime_compatibility/` | Προσαρμογές συμβατότητας του βασικού σεναρίου. |
| `source_inventory.json` | Απογραφή των διαθέσιμων πηγαίων αρχείων. |

## Αναδημιουργία των CSV

Από τον κεντρικό φάκελο του συμπληρωματικού υλικού εκτελέστε:

```text
python code/export_aggregate_tables.py --output-dir ../recreated_tables
```

Ο φάκελος εξόδου πρέπει να είναι νέος ή κενός. Το πρόγραμμα χρησιμοποιεί μόνο την τυπική βιβλιοθήκη της Python. Εξάγει τους 21 πίνακες από τις αποθηκευμένες συγκεντρωτικές τιμές, χωρίς επανυπολογισμό μετρικών ή εκτέλεση πειραμάτων.

## Προετοιμασία δεδομένων

Τα `acquire_adult_sources.py`, `validate_adult_sources.py` και `build_age_semantic_hierarchy.py` βρίσκονται στο `verified_sources/python/`. Η απόκτηση απαιτεί σύνδεση στο διαδίκτυο και γράφει στους φακέλους `data/` και `manifest/`. Η επικύρωση και η κατασκευή της ιεραρχίας απαιτούν τις διαδρομές εισόδων και εξόδων που ορίζουν τα προγράμματα. Βλ. [πηγές δεδομένων](../data_sources/README.md) και [ιεραρχίες](../hierarchies/README.md).

## Όρια εκτέλεσης

Η συλλογή περιλαμβάνει επιλεγμένα αρχεία και δεν αποτελεί αυτοτελές περιβάλλον επανεκτέλεσης. Ορισμένες μονάδες απαιτούν Windows, συγκεκριμένη διάρθρωση αρχείων, ενδιάμεσα δεδομένα και ελέγχους ταυτότητας ή πρόσβασης που συνδέονται με το αρχικό περιβάλλον. Οι έλεγχοι αυτοί παραμένουν ενεργοί και μπορεί να απορρίπτουν εκτέλεση με τα διατιθέμενα αρχεία.

Οι ατομικές προβλέψεις, οι αντιστοιχίσεις εγγραφών και τα λεπτομερή ενδιάμεσα αποτελέσματα δεν περιλαμβάνονται. Για πλήρη επανεκτέλεση απαιτούνται προετοιμασία συμβατού περιβάλλοντος και παραγωγή των αναγκαίων εισόδων. Δεν έχει επαληθευτεί πλήρης επανεκτέλεση όλων των πειραμάτων σε ανεξάρτητο υπολογιστή. Βλ. [καταγεγραμμένες εκδόσεις](../environment/README.md) και [οδηγίες ελέγχου](../docs/VALIDATION_AND_USE.md).
